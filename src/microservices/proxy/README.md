# Proxy Service (ASP.NET Core 9)

Прокси-сервис для постепенной миграции от монолита к микросервисной архитектуре.

## Функциональность

- **Маршрутизация запросов**: Направляет запросы либо на монолит, либо на соответствующие микросервисы
- **Постепенная миграция**: Поддерживает процентную миграцию пользователей на новые микросервисы
- **Health check**: Эндпоинт `/health` для проверки состояния сервиса
- **Консистентное хеширование**: Гарантирует, что один пользователь всегда попадает на один и тот же сервис

## Конфигурация

Сервис настраивается через переменные окружения:

| Переменная | Описание | Пример |
|------------|----------|---------|
| `MOVIES_SERVICE_URL` | URL микросервиса фильмов | `http://movies-service:8001` |
| `MONOLITH_URL` | URL монолитного приложения | `http://monolith:8002` |
| `GRADUAL_MIGRATION` | Включение постепенной миграции | `true` |
| `MOVIES_MIGRATION_PERCENT` | Процент пользователей на микросервисе | `50` |

## Маршрутизация

### Всегда на монолит:
- `/api/users`
- `/api/payments` 
- `/api/subscriptions`

### Миграция (монолит ↔ микросервис):
- `/api/movies`
- `/api/movies/health`

### Health check:
- `/health` - возвращает 200 OK

### По умолчанию:
Все остальные запросы идут на монолит.

## Алгоритм миграции

1. Извлекается ID пользователя из заголовка `X-User-ID` или используется IP-адрес
2. Вычисляется MD5 хеш от ID пользователя
3. Берутся первые 2 байта хеша и вычисляется остаток от деления на 100
4. Если результат меньше `MOVIES_MIGRATION_PERCENT`, запрос идет на микросервис
5. Иначе запрос идет на монолит

## Переменные окружения для Docker Compose

```yaml
environment:
  - MOVIES_SERVICE_URL=http://movies-service:8001
  - MONOLITH_URL=http://monolith:8002
  - GRADUAL_MIGRATION=true
  - MOVIES_MIGRATION_PERCENT=25
```

## Особенности

- Использует минимальный API ASP.NET Core 9
- Поддерживает копирование заголовков и тела запроса
- Обрабатывает ошибки прокси с кодом 502
- Включает логирование ASP.NET Core
